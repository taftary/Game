# Notion — autosave-persistence

## Status

`draft`

## Context

Milestone v0.3.0 (player-facing layer), spec
[`cosmic-navigation-engine-v0.4.md`](../../../docs/techstack/cosmic-navigation-engine-v0.4.md)
§10 (Persistence — resolved for v0.4 scope). Decided by ADR-004 in
[`../../docs/decisions/`](../../../docs/decisions/). Procedural regions are
never saved (ADR-019 determinism); the payload is ship + navigation +
metadata.

## Problem & Needs

- Sessions must resume deterministically mid-flight, mid-transition,
  mid-handoff without storing regenerable content.

## Goals

1. **Binary autosave** persisting: ship state (active-frame ID, 6D
   position/velocity in-frame, orientation quaternion, mass, fuel,
   active control state); navigation state (select-to-focus target,
   active transition plan, time-compression mode/multiplier); metadata
   (format version, master seed, real-world + simulation timestamps,
   session playtime, catalog version IDs, integrity checksum).
2. **Triggers:** confirmed frame transitions, completed SOI handoffs,
   fly-to start/completion, explicit suspend/quit, user-configurable
   periodic interval.
3. **Atomic writes:** temp file + rename; ≥ 2 rotating recovery
   snapshots.

## Non-goals

- Procedural region caching (regenerated by ADR-019 determinism).
- Migration tooling beyond version reject + checksum verify (format v1
  has no predecessors).

## Users / Stakeholders

- Players: never lose a session.
- Developers: deterministic resume for debugging long journeys.

## Roles

Author: PO (2026-09-17). UX consulted (required if player-facing): pending
— save indicators/interval setting are player-facing; consult before
`draft → planned`. ARCHITECT consulted (required if cross-module): pending
(persistence + all navigation state).

## Functional requirements

- Binary writer/reader with format-version + integrity checksum.
- All ADR-004 triggers wired to engine events.
- Atomic rename + snapshot rotation; corruption falls back to the
  previous snapshot.

## Non-functional requirements

- Save round-trip test: resume bit-identical simulation state
  (deterministic resume, spec §10).
- Quality gates in `docs/techstack/quality.md` stay green;
  `persistence.md` updated.

## Definition of Done

- [ ] Round-trip tests: resume mid-flight, mid-fly-to, post-handoff —
  state identical.
- [ ] Corruption test: truncated save rejected via checksum, recovery
  snapshot loads.
- [ ] Every ADR-004 trigger demonstrably fires (event log evidence).

## Constraints & Assumptions

- ADR-004 draft becomes binding here.
- Save format documents catalog version IDs (ADR-020) so epoch-mismatched
  saves are detectable.

## Open questions

- Configurable interval default + range (UX input at plan time).
