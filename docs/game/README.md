# Game — what PlanetCrafter is (detailed)

Seamless procedural universe: zoom from **galaxy → system → planet globe →
orbit**, descend **orbit → atmosphere → sky → soil**, land, explore varied
planets, and build robot-operated colonies — then launch and travel onward.

## Core loop

**Explore → land → build → launch.** Survey from orbit, pick a landing site,
build a colony, put robots to work extracting and hauling, return to orbit
with cargo, and jump to the next world.

## Pillars

- **Seamless scale journey** — one continuous camera path from cosmic to ground.
- **Planet variety** — composition, atmosphere, terrain, and resources differ
  per deterministic seed.
- **Colonies + robots** — building is the progression sink; robots work, you direct.
- **Mobile-first** — phones and tablets are first-class; desktop adds fidelity,
  not different gameplay.
- **Deterministic procedural** — same seed, same universe, every platform.

### Inspirations (directional, not clones)

Planet Crafter (terraform/build loop), No Man's Sky (scale journey), Factorio / Satisfactory (automation via robots).
