# Code of Conduct

Contributors are expected to be respectful, precise, and constructive.

Discussion should focus on the code, documentation, evidence, and user impact.
Harassment, discrimination, personal attacks, and intentionally disruptive
behavior are not acceptable.

Report concerns to the project maintainers through the repository's issue
tracker, or directly to a maintainer for sensitive matters. Maintainers will
review reports confidentially and may moderate or remove contributions that
violate this standard.
