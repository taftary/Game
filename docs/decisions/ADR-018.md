# ADR-018: Physics per scale — cheapest-correct models + symplectic integration

- **Status:** binding (2026-09-17, `plans/v0.1.0/scale-physics` done:
  `engine::physics` implements the model table; Keplerian table is the
  documented ephemeris stand-in until `star-catalog-streaming`)

## Context

Uniform-fidelity N-body across all scales is computationally impractical
and unnecessary (spec §5). Each scale needs the cheapest model that is
visually and physically indistinguishable from correct.

## Decision

- **Per-scale model table (spec §5):** static procedural density field
  (cosmic web/supercluster); Miyamoto-Nagai disk + NFW halo analytic
  potential (Local Group / Milky Way bulk kinematics; a = 6.5 kpc,
  b = 0.26 kpc, r_s = 20 kpc); real Gaia proper motions (solar
  neighborhood); precomputed ephemeris (solar-system background bodies,
  see ADR-020); closed-form Keplerian elements for the ship's dominant
  two-body case with soft patched-conic blending (ADR-014) past the 10⁻³
  acceleration threshold; seed + real exoplanet population statistics for
  procedural bodies.
- **Symplectic integration (velocity Verlet / leapfrog)** for any
  numerically integrated regime — required for long-session energy
  stability; naive Euler visibly drifts orbits.
- **Unit non-dimensionalization** per active frame (spec §5): AU/day/
  solar masses in the solar-system frame (G ≈ 1), km/s/planet masses in
  planetary frames — raw SI is poorly conditioned for `f32`/`f64` force
  math at 10²⁶ m / 10⁴² kg.

## Consequences

- Simulation docs ([`../techstack/simulation.md`](../techstack/simulation.md))
  gain the per-frame unit table when `plans/v0.1.0/scale-physics` is planned.
- Long-session orbital regression tests become part of the validation
  plan (open item, spec §10).
