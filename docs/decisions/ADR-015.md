# ADR-015: Time compression — explicit state machine per reference frame

- **Status:** draft (2026-09-17, proposed by navigation-engine spec
  [`cosmic-navigation-engine-v0.4.md`](../techstack/cosmic-navigation-engine-v0.4.md)
  §2; binding when `plans/v0.1.0/time-compression` lands)

## Context

Physics must run true real-time near bodies (precision piloting, ~90 min
low orbits) but galactic rotation periods (~225 Myr) are meaningless to a
human player. A global time multiplier desynchronizes at SOI handoffs.

## Decision

- Time compression is an **explicit state machine tied to reference-frame
  occupancy** (ADR-012), never a global multiplier.
- True real-time whenever the ship is within a gravitationally
  significant radius of another body; smooth compression when far from
  all bodies.

## Consequences

- Compression mode/multiplier is persisted navigation state (ADR-004).
- HUD displays real-time vs current ratio + state-machine mode (spec §10;
  `plans/v0.3.0/navigation-hud`).
- Physics integrator choice (ADR-018) must remain stable across
  compression transitions.
