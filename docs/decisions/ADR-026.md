# ADR-026: Sphere-bounded descriptor, procedural GPU tracers, non-blocking rebase

- **Status:** accepted (2026-09-23, PO + ARCHITECT decision)
- **Extends:** ADR-025 (field render, `WebField` sidecar, tiering rule,
  carried invariants), ADR-023 (cosmic player, inspector, camera and
  picking contracts), ADR-013 (floating origin, camera-relative `f32`
  upload)
- **Amends:** ADR-025 §1 — the sidecar keeps its *nature* (never
  hashed, never saved, never read by gameplay) but changes *shape*: the
  displaced tracer list is replaced by the displacement grid it was
  derived from.

## Context

v0.3.3 closed with all eight ADR-025 features `done`, and three gaps
remain visible on the shipped evidence shots
(`plans/v0.3.3/cosmic-gas-veil-v2/shots/slab-after-march.png`,
`plans/v0.3.3/cosmic-vista-intro/shots/vista-after.png`):

1. **Nodes outside the sphere.** `descriptor_radius_mpc` is a camera /
   validation value, not a generation cut: stage C extracts peaks over
   the entire 512 Mpc periodic box (`classify.rs`, `border_cells() =
   0`) and `assemble()` converts every accepted peak unclipped
   (`descriptor.rs`). Tracers and the veil *are* cut to 250 Mpc
   (`field_export.rs`, `cosmic_veil.rs`, `MARCH_FRAG` ray–sphere), so
   the corner shell — ≈ 51 % of the box volume — carries nodes, links,
   glow, hub impostors and members with no field around them. This was
   a recorded PO deferral (`plans/v0.3.2/cosmic-scale-player/update-2026-09-18-2328`,
   "cubic-boundary treatment: clip vs fade").
2. **The application stalls when the ship travels.** Crossing
   `REBASE_DISTANCE_MPC` (50 Mpc) makes `tick_cosmic` call
   `refresh_cosmic()` synchronously inside `RedrawRequested`. That
   path rebuilds the 128³ veil volume with a blocking fence wait, the
   whole HDR/bloom chain, and the inspector-tab buffers — none of
   which depend on the origin — plus `splat_records` over ≈ 1.1M
   tracers twice, when only the `pos` translation changes.
3. **Filaments do not read.** One tracer per 4 Mpc lattice cell
   cannot resolve a 1–2 cell-wide filament; the CPU-side 8× refinement
   (`WebField::refine`) exists but was never wired because 8.4M
   tracers × 16 B ≈ 134 MB of vertex data and a ≈ 1 s CPU pass per
   seed are not acceptable on any tier.

## Decision

1. **The descriptor sphere is a generation cut.** Peaks whose refined
   position lies outside `descriptor_radius_mpc` are rejected before
   greedy acceptance; links and glow inherit the cut because they are
   derived from nodes. `WebNode::position_mpc` is thereby bounded by
   the radius, as its documentation already claims. This changes the
   hashed descriptor: `UNIVERSE_VERSION` 3 → 4, committed web vectors
   re-recorded, home-node and calibration bands re-verified (node
   density inside the sphere rises since `target_node_count` is
   unchanged — the calibration bands decide whether it is retuned).
   Saves follow the existing `UNIVERSE_VERSION` migration path
   (ADR-004; precedent `cosmic-web-mass-rank-fix`).
2. **Tracers are generated on the GPU, never stored.** `WebField`
   exports the growth-scaled displacement grid `D₊·∇Ψ` (128³ ×
   RGBA16_SNORM, ≈ 16.8 MB) instead of the displaced tracer list; the
   splat vertex shader maps `gl_VertexIndex` → Lagrangian cell +
   sub-sample → trilinear displacement fetch → Eulerian position, and
   samples the existing R8 density volume for colour and kernel. The
   sub-sample factor per cell is a **tier draw count** (Low 1 /
   Medium 2 / High 8 — starting values, measured), not a precompute.
   A per-seed compact cell list (Lagrangian cells whose displaced
   centre lands inside the sphere, ≤ 50 ms once per seed) bounds the
   invocation count; there is no per-travel CPU work on tracers.
   `WebField.tracers`, `splat_records`, and the 16 B `SplatVertex`
   stream retire (todos in the replacing feature, never implicit).
   The CPU mirror of the shader mapping (`displace_sample`) is the
   determinism / pin tool for tests.
3. **Rebase never blocks the frame.** The origin rebase rebuilds
   only origin-dependent resources (after §2: the hub/member glow
   buffer). The CPU build runs on a worker thread using the house
   pattern (`std::thread` + `mpsc`, generation-tagged request,
   latest-wins coalescing, `try_recv` per frame, join on drop —
   `engine::catalog::io::TileLoader`, `debug::sky` planner); the
   main thread only swaps the `Subbuffer` when a result for the
   current generation arrives. Origin-independent resources (veil
   volume, HDR chain, inspector buffers) rebuild on reseed and
   swapchain recreate only. No fence wait is ever issued from the
   frame loop. This sets the precedent that `crates/debug` may own
   worker threads for GPU-upload preparation; no async runtime.
4. **Grading moves to a transfer function, not more stops.** One
   shared GLSL transfer snippet (splat / sprite / march) maps
   `log2(1+δ)` to emission with a floor at the mean density (below
   the mean → near-black; the indigo backdrop comes from the clear
   colour, never from additive light), a contrast exponent on the
   filament band, and a soft radial fade over the last ≈ 30 Mpc of
   the sphere so the rim is never a hard limb.
5. **Hubs are compact.** Core sprites are pixel-capped; member
   scatter is the visible mass of a hub; bloom widens a small core
   rather than a world-sized disc. The vista and slab presets frame an
   interior window whose frustum footprint at the slab stays inside
   the sphere cross-section, so no preset shows the sphere edge.
6. **Invariants carried forward, unchanged.** Un-flipped
   `directx::perspective`; `ndc = (2u−1, 1−2v)` picking on
   `web.nodes` only; marker via `world_to_pixels`; every bloom /
   march target written once then only read (Intel UHD 620 rule);
   hashed engine paths keep integer decisions + `sqrt`-only;
   fragment shaders stay `fract`-hash / arithmetic only — the
   displacement fetch is a **vertex-stage** texture read, which the
   mobile fill-rate rule does not govern (recorded explicitly in
   `rendering.md`).

## Consequences

- `engine::universe::web` changes hashed output for the first time
  since the mass-rank fix: `UNIVERSE_VERSION = 4`; every pinned vector
  and band test is re-recorded in one feature (`cosmic-sphere-clip`)
  and nothing else in the version touches hashed paths.
- `WebField` loses `tracers` and gains `displacement`; resident
  sidecar goes from ≈ 16 MB (tracers) to ≈ 16.8 MB (grid) + a ≈ 4 MB
  cell list; GPU vertex memory drops from ≈ 17 MB × 2 buffers to zero
  for tracers. Boot cost for the export drops (no second displacement
  loop).
- Vertex-stage texture fetch becomes a required device feature on
  every tier (universal on Vulkan 1.0 hardware; recorded in
  `quality.md` alongside the per-tier draw counts).
- `crates/debug` gains a worker-thread precedent; `architecture.md`
  records the rule (worker owns `Arc` clones of immutable inputs,
  never touches Vulkan objects; the main thread owns every upload).
- Captures stay byte-identical per `(build, seed, GPU)`; the trilinear
  fetch makes cross-vendor identity impossible, which was already the
  case for the raymarch.
- Lands with `plans/v0.3.4/` (six features, one commit each on branch
  `v0.3.4`).
