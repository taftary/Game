# ADR-003: Analytic atmosphere and sky model

- **Status:** binding (2026-09-17, `plans/v0.2.0/depth-cueing` implements
  the Rayleigh/Mie source terms and mobile fallback)

## Context

Rayleigh and Mie scattering are physically valid only while the camera is in
an atmosphere (waypoints 7-10). Vacuum regimes use the separate cue models in
ADR-021. The renderer must provide a deterministic, low-cost atmosphere model
without introducing a GPU-only dependency into the headless engine tests.

## Decision

- Use an analytic single-scattering Rayleigh approximation with wavelength
  dependence proportional to `lambda^-4` and caller-supplied air mass.
- Use a bounded Henyey-Greenstein phase approximation for Mie scattering;
  anisotropy is a calibration parameter, not a replacement for the physical
  scattering basis.
- Expose the result as a linear-radiance source term. Exposure and ACES tone
  mapping remain the single downstream calibration path.
- On Low tier, use the reduced anisotropy fallback from
  `engine::render::cue::atmosphere_radiance`; it preserves the same source
  contract and cue direction while reducing angular complexity.
- Do not use atmospheric haze in Solar-System, stellar-neighborhood,
  interstellar, local-intergalactic, or cosmic-web regimes.

## Consequences

- The atmosphere kernel is pure and headless-testable; renderer binaries may
  consume it without moving simulation or camera logic into `engine::render`.
- Parameters remain tunable for perceptual readability, but tuning cannot
  reverse wavelength ordering or make a vacuum regime atmospheric.
- A future precomputed or multi-scattering model can replace the source
  implementation behind the same linear-radiance boundary.
