# ADR-025: Field-based cosmic-web render (non-hashed `WebField` sidecar)

- **Status:** accepted (2026-09-20, PO + ARCHITECT decision)
- **Extends:** ADR-023 (stage-0 web, cosmic player, inspector tab, camera
  and picking contracts all stay as specified there)
- **Supersedes in part:** ADR-024 — the "render-only, `engine::universe`
  untouched" rule is lifted for one narrowly scoped export; every other
  ADR-024 rule (no hash change, no save change, pins extended not
  loosened) stays in force.

## Context

`cosmic-web-illustris-look` (ADR-024) took graph decoration to its limit:
seven grading rounds in one day, and the build still reads as dotted
straight links with cotton hubs instead of the Illustris reference
(`docs/reports/images/target.jpeg`, described in
`docs/reports/2026-09-20-cosmic-web-visual-description.md`). The gap is
structural — filament curvature/branching, walls, black voids, hub
hierarchy, density-graded color, wide bloom — and cannot be closed by
tuning constants on the link graph
(`docs/reports/2026-09-19-cosmic-web-visual-architecture.md` §11).

The engine already computes what Illustris-style renders splat: stage B
(`engine::universe::web::displace`) produces ~2M Zel'dovich tracer
positions and discards them after NGP deposit; stage C classifies every
cell as void / sheet / filament / node and only the node peaks survive
into the descriptor.

## Decision

1. **Export the field, never hash it.** `engine::universe::web` gains
   `generate_cosmic_web_with_field(seed, params) -> (WebDescriptor,
   WebField)`. `WebField` holds the displaced tracers inside the
   descriptor sphere (position + smoothed local density) and the 128³
   density/T-web-class grid. `generate_cosmic_web` keeps its signature
   and result byte-for-byte (`web_hash` vectors, `UNIVERSE_VERSION`,
   content IDs, saves — all unchanged; pinned by the existing
   determinism tests plus a new equality pin between the two entry
   points). `WebField` is a **render sidecar**: it is never hashed,
   never saved, never read by gameplay (selection, fly-to, home node,
   spawn all stay on `WebDescriptor`).
2. **Render the field, keep the graph for gameplay.** The cosmic
   surfaces (Game Demo + Cosmic Web inspector) draw: adaptive-kernel
   tracer splats colored by a single density ramp
   (`cosmic-tracer-splat`); a depth window — visibility fog on every
   cosmic draw + an inspector slab mode + near-orthographic inspector
   FOV (`cosmic-depth-window`); a mass-rank hub hierarchy with member
   galaxies (`cosmic-hub-hierarchy`); a grid-driven gas veil
   (`cosmic-gas-veil-v2`) — cell sprites on Low, quarter-res
   emission-only raymarch on Medium/High; a write-once mip bloom chain
   (`bloom-mip-chain`); a vista intro for the demo
   (`cosmic-vista-intro`). Grain, beads, smoke puffs, and the
   braid/spine/strand enrichment retire once their replacement lands
   (each retirement is a todo in the replacing feature, never implicit).
3. **Reproducible evidence first.** `cosmic-capture-harness` lands
   before any visual feature: fixed seed + camera presets → PNG, so
   every DoD A/B against `target.jpeg` is a file in the repo history,
   not a memory.
4. **Tiering rule.** Every v0.3.3 cosmic feature ships a Low path that
   holds `docs/techstack/quality.md` budgets (tracer count, veil sprite
   count, bloom target count are tier constants). Raymarch is
   Medium/High only and never load-bearing: Low must read as the same
   web with less body, not a different picture.
5. **Invariants carried forward, unchanged.** Un-flipped
   `directx::perspective`; `ndc = (2u−1, 1−2v)` picking on
   `web.nodes` only; marker via `world_to_pixels`; bloom/raymarch
   targets written exactly once then only read (Intel UHD 620 rule,
   `docs/reports/2026-09-19-intel-hdr-bloom-corruption.md`); hashed
   engine paths keep integer decisions + `sqrt`-only; per-pixel shaders
   stay `fract`-hash / arithmetic only (mobile fill-rate rule).

## Consequences

- `engine::universe::web` is touched for the first time since ADR-023,
  in an additive way: one new public struct + one new entry point, the
  existing entry point delegating to it. Boot cost +≈50–100 ms and
  ≈16 MB resident for the sidecar at nominal params (measured by the
  `web-field-export` DoD, tiered if the cold-start gate is threatened).
- New crate dependency for the capture harness (`png`, dev/debug crate
  only) — SECURITY reviews it; release binary (`game`) unaffected.
- `docs/techstack/quality.md` gains rows for tracer counts per tier,
  veil sprite / raymarch budgets, and the new bloom target count;
  `rendering.md` cosmic section is rewritten around the field render;
  `docs/game/universe.md` mentions the sidecar.
- The Game Demo player is *inside* the web with a perspective camera
  and will never match the outside near-orthographic reference 1:1;
  the vista intro is the matching shot, the immersive view inherits
  the materials.
- Roadmap items closed or re-homed: "volumetric bodies" and "quad node
  impostors" (ADR-024 follow-ups) land here; "sheet-sprite render +
  density export" (milestones cosmic roadmap) is realised by
  `web-field-export` + `cosmic-gas-veil-v2` **without** the
  `UNIVERSE_VERSION` bump that roadmap assumed, because nothing hashed
  changes.
- Lands with `plans/v0.3.3/` (eight features, one commit each on
  branch `v0.3.3`).
