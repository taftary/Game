# ADR-011: Re-sequence build order — Universe maps (M5) before descent (M2)

- **Status:** accepted (2026-09-16, PO decision)

## Context

Milestones were numbered M0–M8 in suggested build order with M2
(descent slice, [`journey.md`](../game/journey.md) levels L5–L7) next.
PO decision: target the full journey top-down — build the upper levels
(L1–L4 maps) first, descent second. Reasons: travel and landing-site
selection have no maps to depart from; universe generation
(seed → galaxy → systems → planets) is foundational data even the
single-planet viewer consumes; the journey state machine then grows
top-down in zoom order, matching the drill-down diagram in
[`journey.md`](../game/journey.md).

## Decision

- Execute M5 content ("Universe v1", maps scope per
  `plans/universe-maps/`) before M2/M3/M4. Execution order: M0, M1,
  M5, M2, M3, M4, M6, M7, M8.
- Milestone numbers are labels, not sequence. Historical plans
  referencing "M2 descent" stay literally true; no renumbering, no
  rewriting of done plans.
- Landing-site selection moves from M5's bullet to the descent
  milestone (M2): site candidates need stage-3 surface data
  (flatness/resources/hazards per [`universe.md`](../game/universe.md))
  and are consumable only once descent exists. Orbit remains the
  arrival state of the maps milestone ("holding state" per
  [`gameplay.md`](../game/gameplay.md)).

## Consequences

- Risk #1 (seamless descent on low-end phones) stays open longer;
  its fades/budgets are unchanged.
- The [`journey.md`](../game/journey.md) f64 rule activates with the
  maps milestone (galactic extents need f64/log-compressed
  coordinates); rendering stays f32 camera-relative.
- `engine::universe` stages 1–2 (galaxy → systems, system → planets)
  land with the maps milestone; stage 3 (planet → surface) stays with
  the descent/surface milestones.
- [`universe.md`](../game/universe.md)'s "surface chunk groupings
  (defined in M2)" reference stays true (numbers fixed).
- Interplanetary transit ships as a timed, cancellable-before-commit
  action ([`gameplay.md`](../game/gameplay.md)); its resource/fuel
  cost hooks to the colonies/resources milestone (M4).
