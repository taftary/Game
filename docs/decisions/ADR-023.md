# ADR-023: Cosmic-scale player in the debug demo + generated cosmic web

- **Status:** accepted (2026-09-18, PO + UX + ARCHITECT decision)
- **Extends:** ADR-022 (unified shell intact — nav model, top bar, dropdown,
  docks, widget, parity registry all stay; this ADR adds content, it
  removes nothing)

## Context

The v0.3.1 shell unified the debug windows, but the Game Demo tab only
followed the journey layer (map navigation, no player) and the W1/L1
Cosmic Web dimension tab was an empty placeholder: the starting
dimension of the game could neither be seen, inspected, nor flown in
(`plans/v0.3.2/cosmic-scale-player`, PO decision 2026-09-18 — the main
game notion: a player in space navigating the Cosmic Scale).

## Decision

- **Stage-0 generation** (`engine::universe::web`, pure + deterministic):
  seeded Zel'dovich web — Gaussian initial field on an integer lattice
  (Irwin–Hall shaping, dyadic smoothing) → displacement `x = q − D₊·∇Ψ`
  → T-web classification (Jacobi eigensolver, sqrt-only, fixed sweeps)
  + Press–Schechter n=0 rank masses → descriptor (nodes, filament
  links, dwarf glow, tagged home node). One deterministic sphere
  (~250 Mpc, ~6k nodes / ~23k links / ~150k glow). `UNIVERSE_VERSION`
  1 → 2 (stage 1–2 streams are domain-separated and untouched, so
  galaxies/systems replay identically; only their hashes re-roll via
  the stamp). The web is explicitly procedural (spec §8).
- **Cosmic player** (`debug::cosmic_player`, window/GPU-free): the
  player *is* an `engine::flight::ShipState` in `FrameId::Cosmological`
  (spec §10 envelope, zero live gravity per spec §5), spawned inside a
  filament near the home node. Free flight + time compression (10⁹
  ceiling) + click-select/`E` fly-to assist reuse the shipped
  `engine::flight`/`time` APIs read-only. stepping uses one exact
  `step_free_flight` per frame with dt in **frame time units (Gyr)** —
  spec-clarification recorded here: `thrust_accel_frame` converts with
  `time_s²/length_m`, so the step dt must be expressed in the active
  frame's time unit (the `step_free_flight` doc string saying "real
  seconds" holds only for SI-time frames; the function is untouched).
- **Player camera + marker** (`debug::cosmic_camera`): Chase (default) /
  Orbit / FirstPerson on `P`, un-flipped `directx::perspective` with
  MapOrbitCamera-style derived near/far, f64 anchor with camera-relative
  `recenter` uploads (ADR-013), 50 Mpc buffer rebase. The marker reuses
  the pinned `world_to_pixels` + dot/arrow/`YOU` path (FirstPerson hides
  it by construction); the inspector player point is map content, not
  the UI marker.
- **Game Demo rebuild**: demo content becomes `ViewContent::CosmicWeb`
  (player scene + live `game::hud`); journey maps leave the demo but
  stay fully functional in their tabs. Input is demo-first for
  drag/wheel/`P` (an armed walker persists across screens); `E` is
  context-dependent (fly-to in the demo, travel-begin on tabs — the `T`
  dual-binding precedent). Registry grows by exactly one action
  (`FlyToToggle [E]`, 44 → 45).
- **Cosmic Web tab** (fourth absorbed view, `debug::cosmic_web`):
  read-only orbit/pan/zoom inspector over the shared descriptor with
  node click-readout and the live player point; never mutates
  journey/sim state (pinned). Supercluster/LocalGroup tabs stay
  placeholders.
- **Real pill/console feed**: the fake `preview()` seed data and the
  `TransitionPanel` (which nothing ever fed for real — `WaypointLeg`
  cannot express an intra-web leg) are deleted; the pill shows live
  fly-to easing progress, the console shows pilot-action lines.
- Reference image step dropped (PO decision): no file under `assets/`;
  the visual target lives in the notion/plan text.

## Consequences

- `docs/game/controls.md` (demo flight keys, Cosmic Web tab, `E`
  dual-binding), `docs/game/journey.md` (L1 traversable-in-demo, tab
  mounted), `docs/game/universe.md` (stage 0), `docs/techstack/
  architecture.md`, `docs/techstack/rendering.md` (cosmic
  marker/camera contract), milestones v0.3.2 updated; techstack
  version bumps to `0.33.0`.
- Follow-ups (not this version): frame handoff into the home galaxy,
  `RegionId` Cosmological streaming, sheet rendering, Mpc-formatted
  HUD target lines, release-shell gating of debug UI.
