# ADR-024: Cosmic-web Illustris look (render-only enrichment)

- **Status:** accepted (2026-09-20, PO + ARCHITECT decision)
- **Extends:** ADR-023 (stage-0 web, cosmic player, inspector tab, and all
  rendering contracts stay exactly as specified there; this ADR adds
  enrichment content, it changes nothing structural)

## Context

The stage-0 generator (`engine::universe::web`) is the correct data
authority and stays frozen, but its visuals read as round mist blobs on
straight node-to-node links — far from the Illustris projection target
(`docs/reports/2026-09-19-cosmic-web-visual-architecture.md`
`target.jpeg`: hair-thin threads, gold beads, dark voids, dominant hub).
A full N-body replacement was evaluated and rejected (boot `0.5 s →
minutes`, determinism contract break, no gameplay node data).

## Decision

- **Render-only enrichment** (`debug::cosmic_web` + `debug` shaders):
  frayed braid arms (`3–7` strands/link, two variants past 20 Mpc),
  WS1 link-graph skeleton (degree-`≥3` bifurcations + seeded spine
  sub-segments), tangent-aligned stretched smoke sheaths (core + halo
  tiers), gold bead points (`≤60k`, `cosmic_web/bead` stream) riding the
  existing glow `PointList` (pick-ignored), faint-thread alpha floor
  `0.05 → 0.03`. No new pipelines, no new dependencies, no new
  `unsafe`, no `UNIVERSE_VERSION` bump, no save change.
- **Budget rule armed, not triggered:** Low-tier fallback order is beads
  → halo smoke → strands; nominal headless
  (`smoke51953 grain800000 beads59958 impostors18000`) holds all budgets
  so nothing is gated off.
- **Pins extended, not loosened:** `cosmic_shader_safety_pins` keeps the
  `rl > 1e-10` side guard and the `1.0 - r2` rim-zero literal on the new
  sheath shaders; bloom write-once, un-flipped projection, marker and
  picking paths unchanged.

## Consequences

- `docs/techstack/rendering.md` (Illustris-look paragraph),
  `docs/reports/2026-09-19-cosmic-web-visual-architecture.md` (§10
  follow-up), techstack version `0.33.7 → 0.34.0`, milestones v0.3.2 row.
- Follow-ups (not this feature): volumetric bodies, quad node
  impostors, distance/frustum culling, sheet-sprite render.
