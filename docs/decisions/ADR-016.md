# ADR-016: Depth strategy — log-depth + multi-pass compositing

- **Status:** binding (2026-09-17, landed with
  `plans/v0.2.0/log-depth-rendering`: `engine::render::depth` kernel +
  `engine::render::bands` scheduler + `game_tools --log-depth` 3-band
  demo; proposed by navigation-engine spec
  [`cosmic-navigation-engine-v0.4.md`](../techstack/cosmic-navigation-engine-v0.4.md)
  §4)

## Context

26 decades of scale cannot fit one depth range. A log-depth buffer alone
(Outerra-style `log(z)` in the vertex shader) extends usable range but is
**not** sufficient for all 26 decades in one pass.

## Decision

- **Log-depth buffer** within a single draw pass (vertex-shader `log(z)`).
- **Multi-pass depth compositing** for the full range: distant scale
  bands (cosmic web, galaxy, distant stars) render depth-cleared first,
  skybox-like; current near-field geometry renders afterward with tight
  near/far planes; results are composited.
- Layer sharing is decided **per pair of scales** — no global depth range.

## Consequences

- Interacts with the projection contract in
  [`../techstack/rendering.md`](../techstack/rendering.md): log-depth
  changes what lands in the depth buffer, not the NDC conventions
  (+1 = top row stays true).
- Band/pair assignments are per-tier quality settings; perf budgets in
  [`../techstack/quality.md`](../techstack/quality.md) gain depth-pass
  rows when `plans/v0.2.0/log-depth-rendering` is planned.
